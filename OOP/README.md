This project is  console application created to demonstrate the core principles of Object-Oriented Programming  in a clear and practical way:

 - Abstraction
 Contains abstract classes and their implementations;
 - Inheritance
 Demonstrates class inheritance;
 - Interfaces
 Shows the use of interfaces for loose coupling
 - Polymorphism
 Examples of polymorphic behavior;
 - Virtual methods, overriding
 Demonstrates virtual methods and method overriding;
  - Services

  Program.cs demonstrates practical usage of all OOP principles.
